# README - Calculadora Web com Histórico de Operações

## Descrição do Projeto

Este é um projeto de uma **Calculadora Web** desenvolvida com **HTML5**, **CSS** e **JavaScript**. A calculadora realiza todas as operações básicas (soma, subtração, multiplicação e divisão) e exibe um histórico das operações realizadas ao lado direito da interface. O histórico inclui a data e o horário de cada operação executada, proporcionando um registro completo das interações do usuário com a calculadora.

## Funcionalidades

- **Operações básicas**: Realiza operações de soma, subtração, multiplicação e divisão.
- **Histórico de Operações**: Mostra um registro das operações realizadas, incluindo a data e o horário da execução.
- **Interface simples e responsiva**: A calculadora é fácil de usar e pode ser acessada tanto em dispositivos móveis quanto em desktops.

## Tecnologias Utilizadas

- **HTML5**: Estrutura da página e componentes da calculadora.
- **CSS**: Estilização da página e design responsivo para uma melhor experiência do usuário.
- **JavaScript**: Lógica de funcionamento da calculadora, incluindo a captura e exibição das operações realizadas.

## Como Funciona

1. **Interface de Usuário**:
   - A calculadora é composta por uma área de entrada de números (display) e botões de operação (soma, subtração, multiplicação, divisão).
   - O histórico de operações é exibido à direita da interface da calculadora, onde cada operação é listada com sua data e horário.

2. **Operações**:
   - O usuário pode inserir números e clicar nos botões de operação para realizar cálculos.
   - O resultado da operação será mostrado na tela e a operação será registrada no histórico, com a data e hora exatas da execução.

3. **Histórico**:
   - O histórico é atualizado automaticamente sempre que uma operação é realizada.
   - O histórico contém um registro das operações feitas, incluindo os números envolvidos e o resultado da operação.
